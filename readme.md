## Запуск проекта

1. Поднять кафку docker-compose up
2. Поднять main_api_gateway, send
3. Поднять консьюмеров для llm и консьюмера внутри сервиса отправки сообщений 

Фронт -> API Gateway -> Распределяет по сервисам \
Сообщения кладутся к кафку, консьюмер ллм его читает и обрабатывает, кладет обратно \
Консьюмер БД постоянно кладет сообщения в базу
